# PHOENIX Enterprise v1.0 - Release Notes

**Release Date:** September 1st, 2026
**Version:** 1.0.0 (General Availability)

## Executive Summary
We are thrilled to announce the General Availability (GA) release of PHOENIX Enterprise v1.0. PHOENIX is an AI-powered Digital Scam Investigation Platform built from the ground up for Enterprise SOCs, CERTs, and MSSPs. It provides a Unified Investigation Engine to rapidly correlate URLs, Emails, Messaging screenshots, and Crypto wallets into actionable threat intelligence using our state-of-the-art AI Copilot.

## What's New
- **Unified Investigation Engine**: Centralized data ingestion covering Phishing Domains, Malicious Emails, and SMS/WhatsApp scams.
- **AI Investigation Copilot**: Context-aware LLM assistance for generating executive summaries and extracting IOCs from unstructured data.
- **Threat Intelligence Platform (TIP)**: Native integration with VirusTotal, URLScan, and AbuseIPDB.
- **Enterprise Multi-Tenancy**: Logical isolation of investigation data across organizational boundaries.
- **DevSecOps Ready**: Shipped as hardened Docker containers with production-ready Kubernetes manifests and AWS Terraform modules.

## Known Limitations
- The AI Copilot currently has a maximum context window of 16k tokens. Extremely large email threads must be chunked prior to ingestion.
- The Browser Extension requires manual provisioning in enterprise environments (Chrome Enterprise Policy).

## Upgrade Notes
- **From Beta/RC**: Database migrations must be run sequentially. Execute `alembic upgrade head` before starting the v1.0 backend containers.
- **API Changes**: All v1 API endpoints are now stabilized and locked. No breaking changes will occur on `/api/v1/*` without a major version bump.
