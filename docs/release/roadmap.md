# PHOENIX Product Roadmap

## Q4 2026: Version 1.1 (The Integrations Update)
- **SIEM / SOAR Connectors**: Native webhook integrations with Splunk, Datadog, and Cortex XSOAR.
- **Crypto Forensics Expansion**: Integrating Chainalysis APIs for deep wallet clustering.
- **SSO General Availability**: Full support for Okta and Azure AD via SAML 2.0.

## Q2 2027: Version 1.5 (The AI Expansion)
- **Autonomous Triage**: AI Copilot can automatically classify, score, and close low-confidence phishing reports without human intervention.
- **Custom LLM Bring-Your-Own-Model (BYOM)**: Support for enterprise customers to connect their internal OpenAI/Anthropic instances.

## Q4 2027: Version 2.0 (The Global Platform)
- **Plugin Marketplace**: A public SDK and marketplace allowing third-party security vendors to build native PHOENIX integrations.
- **Community Edition**: A stripped-down, free-to-use version of PHOENIX targeted at academic researchers and independent security analysts.
- **Data Residency**: Expansion of deployment templates to support multi-region localized data storage for strict GDPR compliance.
